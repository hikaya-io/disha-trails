# Disha documentation

Disha is an offline hiking app for iPhone. These pages cover how to use it, where maps and guides are available, and how to ask for more.

<Callout type="beta">
Disha is in beta on TestFlight. The app and these pages change as the beta does.
</Callout>

## Where to start

- **Start here.** [Getting started](/docs/getting-started/): install the beta, download an area and check it works in airplane mode.
- **Offline maps.** [Download maps](/docs/offline-maps/) in the app, and see [where maps are available](/docs/offline-maps/coverage/).
- **Guides.** [Use a guide](/docs/guides/) in the app, and see [which trails have guides](/docs/guides/trails/).
- **Routes.** [Import a GPX file or draw your own](/docs/routes/).
- **Contribute.** [Request a trail](/docs/requests/), [suggest an edit](/docs/edits/), and how [the trail data stays open](/docs/open-data/).
- **Help.** The [FAQ](/docs/faq/) and how to [get help](/docs/support/).

## How Disha works offline

You download a trail or an area while you have a connection. The map, your route, its elevation profile and the guide are then stored on your phone.

Disha makes no network requests while it draws the map, so airplane mode works the same as a full signal.

## The tabs

Disha has five tabs.

- **Map** shows your maps, routes and location.
- **Guides** lists curated trail guides you can install.
- **Routes** is where you import a GPX file or create a route.
- **Offline** is where you download and manage areas.
- **Settings** has units, map layers, attribution and diagnostics.
