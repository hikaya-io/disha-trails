# Get help

## Report a problem in the beta

Send feedback from the TestFlight app. You can attach screenshots there.

If something was slow or went wrong, share diagnostics from Disha too: open **Settings**, then **Diagnostics**, then **Share diagnostics**. Send the file with your feedback.

## Ask a question

Use the [contact form on hikaya.io](https://hikaya.io/contact/). Tell us your iPhone model, your iOS version and what you were doing.

## Fix these docs

If a page is wrong or missing something, use the same contact form and name the page.
