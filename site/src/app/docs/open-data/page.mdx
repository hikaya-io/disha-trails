# Open trail data

Disha's guide data is meant to be open: you will be able to read it on the web without the app, and add to it.

## What it covers

- Seasonal conditions, such as snow, closures and washed-out sections.
- Water points, including whether a source is flowing.
- Stops such as huts, campsites, shops and viewpoints.

## Keeping it current

Old reports shouldn't bury new ones. Hikers vote reports up or down, so the current answer rises, and at the end of each season older comments are rolled into a short summary you can compare year to year.

Stops and the base map come from OpenStreetMap, and reports come from people on the trail. Verified points should flow back into OpenStreetMap over time, so the work helps every map that uses it.
