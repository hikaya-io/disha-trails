# Guides

A guide describes one trail: its line on the map, the stops along it, its distance and climb, and an elevation profile.

## Browse and install

Open the **Guides** tab to see the available guides. Browsing and installing need a connection, so do it on Wi-Fi. Once a guide is installed, it works offline.

## What a guide shows

- The stops on the map and in a list. Stops include springs, huts, shelters, campsites, shops and viewpoints.
- Distance, climb and an elevation profile, taken from the guide's own line.

## Where the data comes from

Guides start from OpenStreetMap data. Disha shows what it has, so a stop that is missing or wrong in OpenStreetMap is missing or wrong here too. You can fix it at [openstreetmap.org](https://www.openstreetmap.org), or [suggest an edit](/docs/edits/).

## Which trails

[Which trails have guides](/docs/guides/trails/) explains the trails page and its tags. To fix something in a guide, [suggest an edit](/docs/edits/).
