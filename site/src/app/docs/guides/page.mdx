# Guides

A guide describes one trail: its line on the map, the stops along it, its distance and climb, and an elevation profile.

## Browse and install

Open the **Guides** tab to see the available guides. Browse and install them on Wi-Fi. An installed guide works offline.

## What a guide shows

- The stops on the map and in a list. Stops include springs, huts, shelters, campsites, shops, and viewpoints.
- Distance, climb, and an elevation profile from the guide's own line.
- What hikers last reported at each stop, such as whether a spring is flowing or a refuge has tent space.

## Where the data comes from

Guides start from OpenStreetMap data, so a stop that is missing or wrong there is missing or wrong in Disha too. You can fix it at [openstreetmap.org](https://www.openstreetmap.org) or [suggest an edit](/docs/edits/). Hikers' reports add current conditions on top. See [open trail data](/docs/open-data/).
