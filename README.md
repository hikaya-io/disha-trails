# Disha trails

Open trail data for [Disha](https://disha.hikaya.io), the offline hiking app: GPX routes from trail races and thru-hikes, and US national forest and park boundaries. The files are free to download. See [ATTRIBUTION.md](ATTRIBUTION.md) for where each one comes from.

## Vote for a trail

Disha adds maps and guides for the trails people ask for most.

1. Look through the [open requests](https://github.com/hikaya-io/disha-trails/issues?q=is%3Aissue+is%3Aopen+label%3Atrail-request).
2. Add a 👍 to a trail you want, or a 👎 to one you don't.
3. Don't see your trail? [Request it](https://github.com/hikaya-io/disha-trails/issues/new?template=trail-request.yml). One request per trail.

Trails with the most votes are built first.

To report a change to a published guide, such as a closed hut or a wrong distance, [suggest an edit](https://github.com/hikaya-io/disha-trails/issues/new?template=trail-edit.yml).

## Download the data

- `trails/` has the GPX routes, and `trails/pct/` the Pacific Crest Trail.
- `national-forests/` has the boundary files.

Open a file on GitHub and click **Download raw file**.
